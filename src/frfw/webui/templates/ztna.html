Zero Trust Network Access Gate

Local, kernel-enforced per-source-IP authorization: a signed-in device's IP is added to the authenticated_ztna_users nftables set for the configured session length, and any firewall rule with "Require ZTNA" checked (see the Rules screen) only matches traffic from a source IP currently in that set. The kernel evicts an expired IP on its own -- no cron job, no userspace polling.
