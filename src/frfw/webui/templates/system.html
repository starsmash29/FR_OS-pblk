System: Post-Quantum Hybrid Key Exchange

Software integrity

FR_OS's files -- the program, its compiled files, its systemd units and scripts, the XDP program -- are compared with the signed release they came from (security-lessons G9, ROADMAP SEC-15), so rewriting pip's install record doesn't hide a change. It covers FR_OS's own files only: a change elsewhere -- another systemd unit, another program, an SSH key -- is not reported. Someone with root can still change this check itself: the check that doesn't trust the router reads its boot medium from another computer (scripts/verify-medium.py).
