TLS Fingerprints

Identifies which TLS software each device uses -- browser, app, library or script -- from the unencrypted first message of every TLS connection (the ClientHello), without decrypting anything. JA4 is stable per client software (the recommended one); JA3 is shown too, but browsers that shuffle their extensions produce a new JA3 on almost every connection.
